# tidyvisor: A Statistical Advisor for Research: Design, Analysis and Interpretation

A chief statistician for R. Before the data are collected, 'tidyvisor'
advises on study design, the unit of replication, sample size (power
analysis) and good research practice, with the reporting guideline for
the field. Given data and a question, it audits the data, checks the
assumptions of the candidate analyses and recommends the analysis, the
test and the plots, with the code to run and what to do when assumptions
fail. Given a fitted result, it explains the numbers in plain sentences,
with its reasons, so the advice can be checked and overruled.
Specialised knowledge lives in the packages that do the analyses, each
of which registers an advisor: 'tidydiversity' for community ecology,
'tidymapr' for spatial ecology and spatial epidemiology, and
'tidyepidemio' for epidemiology.
